# Backlog

Everything left to do, in one list. Each row is a piece of work someone can pick up, what it
can't be done without, and where its details are: the requirements, the design and the
step-by-step checklist stay in the feature document or bug report the row links to. What each
feature is and how far it has got is in the [features index](features/README.md).

**Picking up work** - `python tools/backlog.py list --pc` lists the rows a PC is enough for, and
`python tools/backlog.py show BL-NNN` shows one with its open boxes. Rows marked *good first* are
small and self-contained. External contributions are not being accepted at this time: the
maintainers check `gh pr list` for a draft pull request that already claims a row, then work on a
branch `bl-NNN-short-name` with a draft pull request ([AGENTS.md](../AGENTS.md) "Working with
others"). Rows that need the maintainers wait on them; an issue is the place to argue a case.

**Keeping it current** - for people and assistants alike:
- Starting, finishing, finding or reordering work changes this page in the same change.
- A finished row is deleted once its boxes are ticked in the feature document (git keeps the
  history). A row that is half done says what is left.
- New work gets the next free number (numbers are never reused, so a section's numbers need not
  be in order) and a link to its details. Every unchecked box in a feature document carries its
  row's number, on the box or on a heading above it: `python tools/check_backlog.py` checks that
  (CI runs it).
- The order of section 1 is the maintainers'. The other sections are in a rough order only.
- This page is public: no names, addresses, codes or anything else CONTRIBUTING.md
  "Conventions" keeps out of the repository.

**Needs:** **PC** - the host tests, the PC simulator and the preview are enough; **PC (good
first)** - the same, and small and self-contained · **Panel** - a CrowPanel 7" on the bench ·
**Part** - a module or device, named · **Service** - an outside account or server ·
**Maintainers** - a decision only the maintainers make, their own panels, or a listening check by
ear · a **BL-** number - a decision in section 2 comes first.
