# RoboAlarms identity · initial direction

A geometric R joins a protective house outline. Teal links it to the panel's calm
ready-state palette; the wordmark uses readable UI typography with tight spacing.
Avoid blinking, animated status motifs or decorative effects in documentation.

- Master raster: `src/assets/brand/roboalarms-mark.png` (1280 × 1280, alpha) in the
  documentation repository,
  [RoboAlarms/documentation](https://github.com/RoboAlarms/documentation/blob/main/src/assets/brand/roboalarms-mark.png).
- Downloadable copy: `public/brand/roboalarms-mark.png` there. This repository's front page uses a
  copy of it, `docs/images/roboalarms-mark.png` ([docs/images](images/README.md)).
- Header: mark plus accessible live-text **RoboAlarms** wordmark.
- Teal web accent: #007b7d on light pages; #94eff0 on dark pages.
- Keep clear space around the symbol; preserve aspect ratio. Do not imply certification
  through seals or compliance badges.

Generated with an image-generation model on 2026-09-23 from the prompt below. This is an

## Generation prompt

Use case: logo-brand. Create a professional modern brand symbol for RoboAlarms, an
open-source home alarm system. Asset is a standalone logo mark for a documentation
website header and future product identity. Design a distinctive geometric monogram
combining an angular R with a protective enclosing shape, subtly suggesting a house
without literal clip-art. Confident precise engineered silhouette, simple enough to
recognize at 32 pixels. Flat solid bright teal/cyan mark, crisp vector-like edges, no
gradients, no shadows, no 3D, no textures, no tiny detail. Transparent background with
genuine alpha. Centered single symbol with moderate empty margin. No words, letters
outside the monogram, labels, presentation boards, mockups or watermarks. Output a
single square image.
