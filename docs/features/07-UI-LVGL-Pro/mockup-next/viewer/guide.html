What this is

A mockup of the 7" panel's touchscreen as it is today, built from the same design system: the colours, spacing, radii and sizes come from the layout's globals.xml, the fonts are the panel's Inter and Lucide files, and every part is named after its LVGL component. It is where a change to the screen is drawn and agreed before anyone builds it.

Reviewing

  • Screen shows one screen at its real size (or fitted). Tap the rail, the tiles and the rows to move between screens, as on the panel.
  • Panel, Side by side, Overlay and Difference put the PC preview's picture of the same state beside or over the mockup (in a build made with --shots). Difference is black where they match.
  • Screens under Proposals are changes someone wants to make, with their backlog row and status (draft, approved, rejected, built). A proposal that replaces a screen shows today's beside it; what it changes has a dashed outline.
  • Appearance (Dark, Light, High contrast, High contrast light) recolours every screen with a proposed palette from the layout's themes.xml (BL-132); the viewer remembers the choice. A screen drawn to show one appearance keeps it, whatever the switch says. Dark is today's colours with brighter hints.
  • Coverage lists the preview's pictures that have no mockup screen yet.

Changing it

The sources are in docs/features/07-UI-LVGL-Pro/mockup (its README has the rules): kit/ holds the components, screens/ today's screens, proposals/ the changes being discussed. Build with python tools/ui_mockup.py build --shots and check with python tools/ui_mockup.py check.

Nothing here moves or blinks: the panel's display-safety rules (no flashing) hold in the mockup too.
